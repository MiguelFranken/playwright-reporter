---
title: The admin area
description: What superadmins manage under Administration.
---

Superadmins see **Administration** in the sidebar. It manages the whole instance; team admins manage their own team
from **Team settings** instead.

| Page | What it is for |
| --- | --- |
| **Teams** | Create and delete teams. Teams own projects and memberships. |
| **Users** | Every account: create one, change the instance role, ban, set a temporary password, delete. |
| **Storage** | Where artifacts live and how long screenshots, videos and traces are kept. |
| **Database** | How much run history the database holds, how fast it grows, and how long it is kept. |
| **MCP** | Switch the MCP server on or off, and see every personal access token that can reach it. |
| **Audit log** | Who did what, when. Newest first. |

<Callout title="There is no self-registration">
  Accounts come from an invitation link or a superadmin. The seed creates the first superadmin.
</Callout>
