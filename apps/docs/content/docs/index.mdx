Playwright Reporter is a reporter you add to your Playwright config and a self-hosted Next.js app it streams to. The app
shows runs **while they run**, keeps their history, screenshots, videos and traces, and tells you which tests are flaky,
slow or broken.

## What you get

- **Live runs.** Results, steps and attachments appear within a second or two, over server-sent events, while the
  tests are still running.
- **Sharding built in.** Shards that share a CI run id are merged into one run, auto-detected on GitHub and GitLab.
- **Every artifact.** Screenshots, videos, logs and visual diffs next to the test, and traces in Playwright's Trace
  Viewer, served by the app itself — no third party, works behind a VPN.
- **History and trends.** A dashboard per project, a page per test, per branch and per pull request, with pass rates,
  durations and flaky tests over time.
- **Git and CI aware.** Branch, commit, author, pull request and build link, from Playwright's `captureGitInfo`, CI
  variables or the checkout.
- **No zombie runs.** A run whose reporter died reads as *Abandoned*, recorded by a durable watchdog.
- **AI assistants over MCP.** Claude, Cursor, Copilot, ChatGPT and friends read your test history and debug failures
  with evidence.
- **Teams, roles and invitations.** Superadmins, team admins, members and viewers; teams can't see each other's
  projects.
- **Runs anywhere.** PostgreSQL, and the local filesystem, Vercel Blob or any S3-compatible bucket for artifacts.

## How it fits together

| Part | What it is |
| --- | --- |
| `@miguelfranken/reporter` | The Playwright reporter. Streams runs to the app with a project token; never fails your tests. |
| The app (`apps/web`) | Next.js, PostgreSQL, Better Auth. The UI, the ingest API, the MCP server and the REST API. |
| `@miguelfranken/mcp` | A stdio bridge to the app's MCP server, for clients that only start local servers. |
